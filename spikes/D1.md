### Contributor / architecture fit

- Agent and project already use Rust; measurement FFI (PresentMon, etc.) and privileged helper are natural Rust.
- Option B forces either a second implementation language for core or a .NET/Rust FFI boundary for every action.
- Tauri `invoke` maps cleanly to allow-listed named operations (matches helper design in ARCHITECTURE.md).
