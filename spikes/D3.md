## Anti-cheat (non-injection)

| Path | Injects into game? | Hertzline rule |
|---|---|---|
| PresentMon ETW consumer | No (system ETW; no DLL inject; Flash Injector removed upstream) | Allowed. Some titles may block ETW; then status = unavailable (never fall back to inject). |
| MangoHud | Vulkan layer / GL intercept only when the user launches `mangohud <app>` | Allowed only as **user-opted** wrap + log ingest. Never silent attach to a running anti-cheat process. Overlay/measure off by default when AC detected (AC-6.2). |
| macOS external capture | N/A | Not possible; do not use private APIs or debugger attach for FPS. |

## Privilege (Windows)

- Real-time PresentMon ETW session: admin **or** membership in **Performance Log Users** (official PresentMon README).
- Hertzline must **not** run the whole desktop app elevated.
- Measurement start may request a short-lived elevated PresentMon/helper path (same privilege boundary as D2), or guide the user to join Performance Log Users.
- Local unprivileged smoke on this machine: PresentMon `--timed 2` exited **6** with `failed to start trace session: access denied` (evidence of the documented gate).

## Probe API (in `hertzline-core`)

- `frame_capture::probe_frame_capture()` -> `ProbeReport` (serde JSON).
- `frame_capture::compute_stats_ms(&[f64])` -> avg FPS, 1% low, 0.1% low, variance (AC-1.1 math; mocks labeled in tests).
- Windows: looks for `HERTZLINE_PRESENTMON` or PresentMon on PATH.
- Linux: looks for `mangohud` on PATH.
- macOS: returns `not_possible` for external frame times, `partial` capability.

Example:

```bash
# optional: point at downloaded PresentMon 2.6.0
set HERTZLINE_PRESENTMON=spikes\d3-tools\PresentMon-2.6.0-x64.exe
cargo run -p hertzline-core --example d3_probe --locked
```

Host modules are `cfg`-gated. CI `cargo test` on ubuntu-latest / macos-latest exercises probe serialization and OS-specific assertions (mangohud may be unavailable -> `unavailable` is a valid AC-1.6 failure path; macOS asserts `not_possible`).

## Decision

**Chosen:**

- **Windows:** PresentMon / PresentData **ETW** (MIT, v2.6.0 pin for tooling). No injection. Elevate or Performance Log Users only for the capture session.
- **Linux:** **MangoHud** (MIT, v0.8.4 latest verified) via user-opted launch wrap and CSV/`output_folder` ingest; probe `mangohud`; failure -> unavailable.
- **macOS:** External game frame times **not possible** via supported public APIs; partial display-refresh only (CVDisplayLink / CGDisplay). UI must state this plainly (AC-1.7 / AC-4.23).

Full capture pipeline implementation is **HZ-011**. Sensor licenses are **HZ-007**.
