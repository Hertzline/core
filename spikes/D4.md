## License policy (D4)

1. Third-party code linked into Hertzline binaries must be **MIT, Apache-2.0, or BSD** (or equivalent permissive SPDX), documented in `NOTICE`.
2. **MPL-2.0** (LibreHardwareMonitor) is rejected for linking in v1.
3. Vendor SDKs (NVIDIA NVML runtime, AMD ADLX) are **not redistributed**. Optional later paths may **dynamically load** a system-installed driver library; metrics stay `unavailable` when absent.
4. Missing sensors are labeled `unavailable` / `not_possible` -- never invented (AC-1.2).

## Decision

**Chosen:**

- **Primary sensors:** `sysinfo` **0.40.3** (MIT) wrapping OS APIs for CPU, RAM, disk inventory, network counters, component temperatures, and GPU usage/VRAM where exposed.
- **Rejected:** LibreHardwareMonitor (MPL-2.0); redistributing AMD ADLX/ADL into Hertzline.
- **Optional later:** system NVML for NVIDIA-only extras (temps/clocks) via dynamic load + `nvml-wrapper` license for the Rust bindings; never ship NVIDIA SDK bits.
- **Honesty:** GPU clocks, throttle flags, disk queue, and macOS dedicated VRAM are unavailable / not possible until a documented path exists; collectors implement this in **HZ-012**.
